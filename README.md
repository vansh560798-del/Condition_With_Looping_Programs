## Technologies Used
- TypeScript
- Visual Studio Code
- Node.js

## How to Run

1. Install Node.js.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
tsc Q1.ts
```

5. Replace `Q1.ts` with the program you want to execute.

**Note:** Program Q20 uses `prompt()`, so it must be executed in a browser environment.
